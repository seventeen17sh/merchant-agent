## 数值题的标准 SQL

金额按元、毛利率按百分数校验；忽略列顺序和中文别名差异，排名题保留行顺序。所有 SQL 还会经过相同安全层并加外层行数限制。

### 第 1 题

```sql
SELECT COALESCE(SUM(quantity),0) AS 销量_件 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21'
```

### 第 2 题

```sql
SELECT ROUND(COALESCE(SUM(quantity*unit_price_cents),0)/100.0,2) AS 销售额_元 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21'
```

### 第 3 题

```sql
SELECT ROUND(COALESCE(SUM(quantity*(unit_price_cents-unit_cost_cents)),0)/100.0,2) AS 毛利_元 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21'
```

### 第 4 题

```sql
SELECT ROUND(100.0*SUM(quantity*(unit_price_cents-unit_cost_cents))/NULLIF(SUM(quantity*unit_price_cents),0),2) AS 毛利率_百分数 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21'
```

### 第 5 题

```sql
SELECT COALESCE(SUM(quantity),0) AS 销量_件,ROUND(COALESCE(SUM(quantity*unit_price_cents),0)/100.0,2) AS 销售额_元 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21' AND product_id='P001'
```

### 第 6 题

```sql
SELECT ROUND(COALESCE(SUM(quantity*(unit_price_cents-unit_cost_cents)),0)/100.0,2) AS 毛利_元 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21' AND product_id='P001'
```

### 第 7 题

```sql
SELECT ROUND(COALESCE(SUM(quantity*(unit_price_cents-unit_cost_cents)),0)/100.0,2) AS 毛利_元 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-09-01' AND order_date<'2026-10-01' AND product_id='P001'
```

### 第 8 题

```sql
SELECT ROUND(COALESCE(SUM(quantity*unit_price_cents),0)/100.0,2) AS 销售额_元 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-09-01' AND order_date<'2026-10-01'
```

### 第 9 题

```sql
SELECT p.product_name AS 商品,ROUND(SUM(o.quantity*o.unit_price_cents)/100.0,2) AS 销售额_元 FROM orders o JOIN products p ON o.product_id=p.product_id WHERE o.status IN ('paid','completed') AND o.order_date>='2026-09-01' AND o.order_date<'2026-10-01' GROUP BY p.product_id,p.product_name ORDER BY 销售额_元 DESC LIMIT 3
```

### 第 10 题

```sql
SELECT SUM(on_hand-reserved) AS 可售库存_件 FROM inventory
```

### 第 11 题

```sql
SELECT p.product_name AS 商品,i.on_hand-i.reserved AS 可售库存_件 FROM inventory i JOIN products p ON i.product_id=p.product_id WHERE i.on_hand-i.reserved<p.safety_stock ORDER BY 可售库存_件
```

### 第 12 题

```sql
SELECT i.on_hand AS 账面库存_件,i.reserved AS 占用库存_件,i.on_hand-i.reserved AS 可售库存_件 FROM inventory i JOIN products p ON i.product_id=p.product_id WHERE p.product_name='晨光保温杯'
```

### 第 13 题

```sql
SELECT ROUND(SUM((i.on_hand-i.reserved)*p.current_cost_cents)/100.0,2) AS 可售库存金额_元 FROM inventory i JOIN products p ON i.product_id=p.product_id
```

### 第 14 题

```sql
SELECT p.category AS 类目,ROUND(SUM(o.quantity*o.unit_price_cents)/100.0,2) AS 销售额_元 FROM orders o JOIN products p ON o.product_id=p.product_id WHERE o.status IN ('paid','completed') AND o.order_date>='2026-10-01' AND o.order_date<'2026-10-21' GROUP BY p.category
```

### 第 15 题

```sql
SELECT COUNT(DISTINCT order_id) AS 有效订单数 FROM orders WHERE status IN ('paid','completed') AND order_date>='2026-10-01' AND order_date<'2026-10-21'
```
